# JUAN.OS

A minimalist hacker-inspired personal dashboard built with vanilla HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser. For best results, use a local static server.

## Customize before publishing
- Replace the generic GitHub URL in `index.html` with your profile URL.
- Replace `hello@example.com` with your contact email.
- Add real project links and verified technologies.
- The portrait is stored at `assets/portrait.jpeg`.

## Publish with GitHub Pages
1. Create a repository named `YOUR_USERNAME.github.io` (or use any repository and enable Pages).
2. Upload the project files, keeping the `assets` folder.
3. In repository Settings → Pages, select the branch and root folder.
4. Open the published Pages URL.

The optional ambient sound is synthesized locally by the browser after the visitor enables it; no audio file or external audio service is required.
